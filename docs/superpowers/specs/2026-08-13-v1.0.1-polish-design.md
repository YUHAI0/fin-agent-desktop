# Fin-Agent Desktop v1.0.1 设计说明

> 状态：已完成  
> 日期：2026-08-13  
> 相关：`ROADMAP.md`（v1.0.1 节）

## 1. 目标与原则

**定位不变**：智能投资顾问，服务新手 + 有经验散户（分层），轻量主动 + 深度按需。

**本版本目标**：不引入大型新模块，打磨现有对话 / 组合 / 新闻 / 提醒 / 画像 / 个股页，打通「数据 → 结论 → 行动」闭环。

**原则**：

- 结论可执行（有下一步）
- 页面可跳转 Agent（预填意图）
- 画像可见可改，并影响回复深浅
- 复用现有 Electron + Python Agent 架构，不新增独立服务

**明确不在本版本**：投资仪表盘、Onboarding 向导、Watchlist、研报夹、定时简报、投资日历、再平衡、多股对比、技术指标预警、基金、模拟交易。

## 2. 范围清单

### 2.1 对话与 Agent

- 分析类回复统一结构：结论 → 依据 → 风险 → 下一步行动
- 快捷回复偏行动项（设提醒、组合诊断、深入某指标）
- 工具失败：友好中文错误 + 可用替代方案
- 分析类长回复末尾简短免责声明；简单确认类可省略

### 2.2 个股详情页

- 「让 Agent 分析此股」：跳转聊天并预填 `ts_code` + 名称上下文
- K 线周期扩展：3Y / 5Y

### 2.3 用户画像

- 设置页可视化编辑：风险、周期、板块、经验等级
- `user_profile.json` 新增 `experience_level`：`beginner` | `experienced`（展示：新手 / 老手）
- 画像变更后系统提示词热更新（每次对话刷新 system 中的画像摘要）
- 画像完整度提示（不阻断使用）

**分层效果（仅措辞与密度，不隐藏功能）**：

| 维度 | 新手 | 老手 |
|------|------|------|
| 语言 | 解释术语、多举例 | 直接给数据与结论 |
| 深度 | 简版结构 | 可含完整指标表 |
| 快捷回复 | 偏引导类 | 偏回测/选股/诊断类 |

### 2.4 提醒系统

- 在现有 `ReminderTasksModal` 上增强（不强行改成整页）
- 百分比涨跌幅创建：UI 填 ±X% → 后端取现价换算绝对阈值 → 仍持久化为现有 `price_alert`
- 触发历史：本地记录（如 `alert_history.json`），列表可查看
- 现有列表 / 删除能力保留；可补启用停用若后端已支持

### 2.5 组合页

- 一键「组合诊断」：跳转聊天并预填诊断意图（含当前组合 id）
- 轻量行业分布（简表或饼图）+ 持仓集中度；缺行业字段时显示「未知」并降级

### 2.6 新闻

- Toast：「分析这条新闻对我持仓的影响」→ 预填跳转聊天
- 资讯流中标注与当前持仓相关的条目（名称 / 代码匹配）

### 2.7 数据源体验

- 无 Tushare Token：引导更清晰，可用功能高亮；不可用工具不反复重试
- akshare 关键行情路径失败时自动重试 1–2 次后再报错

## 3. 架构

保持三层，仅补 API / 页面 / 提示词：

```text
Renderer
  ConfigView           → 画像编辑
  StockDetailView      → 分析跳转；K 线 3Y/5Y
  PortfolioView        → 诊断入口；行业/集中度
  ReminderTasksModal   → 百分比创建；触发历史
  ToastView / News     → 持仓关联；快捷分析
  ChatContext          → 预填消息 / 场景意图
       ↓ IPC
Main                   → REST 转发
       ↓
Python fin-agent
  /profile（新或补齐） → CRUD + experience_level
  /tasks（增强）       → 百分比预警换算；触发历史读写
  /portfolio（增强）   → 行业聚合 / 集中度
  Agent core           → 报告结构 + 分层摘要
```

### 3.1 关键数据流

1. **画像**：设置页保存 → `user_profile.json` → Agent 刷新 system 画像段。  
2. **预填跳转**：`navigate` + query / ChatContext 注入；若当前标签正在流式输出则新开标签。  
3. **百分比提醒**：取现价失败则拒绝创建并提示，不写无效任务。  
4. **对话结构**：以 system prompt 约束为主；不做完整报告引擎（留给 v1.1）。

## 4. 错误处理与空状态

| 场景 | 行为 |
|------|------|
| 工具/数据源失败 | 中文原因 + 下一步（重试 / 换源 / 去设置） |
| 无 Tushare Token | 标明需 Token；不刷屏调用不可用工具 |
| 画像不完整 | 可用；提示完善；Agent 默认均衡口径 |
| 组合无持仓点诊断 | 空状态 + 去添加持仓 |
| 新闻匹配不到持仓 | 不打标、不报错 |

## 5. 非目标与依赖后续版本

- 「收藏此报告」→ 依赖 v1.2 研报夹  
- 「加入观察 / 对比」→ 依赖 v1.1 Watchlist / v1.3 对比  
- 组合 vs 基准、最大回撤等重分析 → backlog  
- 仪表盘 / Onboarding / 定时简报 → v1.1 / v1.2  

## 6. 验收要点（手动）

1. 修改画像（含经验等级）后，新对话回复深浅立刻变化。  
2. 个股页「让 Agent 分析」预填正确且不打断进行中的流式输出。  
3. 百分比提醒可创建、可触发，历史可见。  
4. 无 Token 时不出现反复失败的工具调用循环。  
5. 组合诊断在有/无持仓两种状态下行为符合预期。  
6. 新闻 Toast 快捷分析可跳转并带上新闻摘要。
