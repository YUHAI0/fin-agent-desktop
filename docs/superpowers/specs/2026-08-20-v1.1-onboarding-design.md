# v1.1 Onboarding 投资画像向导

> 状态：待实现  
> 日期：2026-08-20  
> 范围：v1.1 四块中的第一块（Onboarding）。仪表盘、结构化报告、Watchlist 不在本文。  
> 相关：`user_profile.py`、`ProfileView.tsx`、`POST /profile`、启动窗口 `#/chat`

## 1. 目标

全新安装时用独立全屏向导收集投资画像，让顾问从第一句对话就知道用户是新手还是老手。向导可跳过；跳过或完成后不再自动弹出。已有 1.0.x 数据的升级用户不看到向导，继续用设置页完整度提示。

## 2. 非目标

- 投资仪表盘、结构化分析报告、Watchlist
- 向导内配置 LLM / Tushare
- 收集精确可投资金额（只存档位）
- 强制填完才能进应用
- 给升级用户补弹向导
- 云同步、自动测试、Mock

## 3. 已确认决策

- 仅全新安装出向导；可跳过；之后只靠设置页完整度提示
- 独立路由 `/onboarding`，不盖在聊天页上，不复用设置表单当开场
- 5 步：经验 → 风险 → 周期 → 关注+回避板块（同一步）→ 金额
- 回避板块可不选；金额含「暂不透露」
- 先向导再进主界面；API 未配置不拦截向导，对话时再走现有设置引导
- 完整度计算仍只看经验 / 风险 / 周期 / 关注板块；金额与回避不算缺项

## 4. 启动分流

主窗口创建时由 **Electron 主进程** 决定加载 `#/onboarding` 还是 `#/chat`，避免先闪聊天页。

状态文件：与 `user_profile.json` 同一配置目录下的 `onboarding.json`。

```json
{
  "status": "pending | completed | skipped | migrated",
  "updated_at": "ISO-8601"
}
```

分流规则：

| 条件 | 行为 |
|------|------|
| 无 `onboarding.json`，且配置目录已有 1.0 数据 | 写入 `status: migrated`，打开 `#/chat` |
| 无 `onboarding.json`，且无 1.0 数据 | 视为 `pending`，打开 `#/onboarding` |
| `status` 为 `completed` / `skipped` / `migrated` | `#/chat` |
| `status` 为 `pending` 或无法识别 | `#/onboarding` |

「已有 1.0 数据」指配置目录（Windows：`%APPDATA%/fin-agent`）中存在任一：

- `user_profile.json`
- `.env`
- `app_config.json`
- 会话目录（`session_store` 使用的 sessions 目录）

迁移读写失败：打日志，打开 `#/chat`，不要把升级用户卡在向导。

向导不得作为默认路由兜底：`/` 与未知 hash 仍按现有逻辑，不误进向导。只有主进程显式加载或用户未完成 pending 时才进 `/onboarding`。

## 5. 向导界面

全屏页，无会话侧栏。标题栏可拖动窗口；Windows 右上为系统按钮留位，macOS 左上为红绿灯留位。

- 顶部：5 段进度
- 右上：**跳过**
- 左下：**上一步**（第 1 步隐藏）
- 右下：第 1–4 步 **下一步**，第 5 步 **开始使用**

向导内选项不含「未知」。设置页仍保留「未知」，用户事后可改回去。

### 5.1 步骤

| 步 | 字段 | 选项 | 进入下一步 |
|----|------|------|------------|
| 1 | `experience_level` | `beginner` 新手 / `experienced` 老手 | 必选其一 |
| 2 | `risk_tolerance` | `Conservative` 保守 / `Balanced` 平衡 / `Aggressive` 进取 | 必选其一 |
| 3 | `investment_horizon` | `Short-term` 短期 / `Medium-term` 中期 / `Long-term` 长期 | 必选其一 |
| 4 | `favorite_sectors` + `avoid_sectors` | 见 5.2 | 关注至少 1 个；回避可空 |
| 5 | `capital_range` | 见 5.3 | 必选其一（含暂不透露） |

本地草稿随点选更新。「下一步」不请求网络。「开始使用」和「跳过」才落盘。

### 5.2 板块

预设芯片（可多选）：新能源、半导体、消费、医药、金融、军工、周期、科技、红利、大盘蓝筹。

另提供「其他」文本框，按中文逗号 / 英文逗号 / 顿号拆分后并入对应列表。

关注与回避使用同一套预设。同一名称可同时出现在两侧（不强制互斥）；实现时不去重跨列表。

### 5.3 金额档位

存稳定英文键，界面显示中文：

| 键 | 文案 |
|----|------|
| `under_5w` | 5 万以下 |
| `5_20w` | 5–20 万 |
| `20_50w` | 20–50 万 |
| `50_100w` | 50–100 万 |
| `over_100w` | 100 万以上 |
| `undisclosed` | 暂不透露 |

缺省（从未选过）不写该字段，或视为未设置；与显式 `undisclosed` 不同：前者算「没答」，后者算「不愿透露」。向导第 5 步必须选一档才能点「开始使用」。

## 6. 跳过与完成

**跳过**

1. 主进程立刻把 `onboarding.json` 写成 `skipped`（不依赖 Python）
2. 导航到 `#/chat`
3. 若草稿里已有已选项，尝试 `POST /profile` 保存；失败不挡跳过、不改 `skipped`

**完成（开始使用）**

1. `POST /profile` 写入 5 步结果（回避可空数组）
2. 成功后再把 `onboarding.json` 写成 `completed`
3. 导航到 `#/chat`
4. 保存失败则留在第 5 步，中文提示可重试；`onboarding.json` 保持 `pending`

Python 尚未就绪：完成按钮进入等待并短重试；超时提示后仍为 `pending`，不进聊天冒充已完成。

## 7. 数据与 API

### 7.1 `user_profile.json`

在现有字段上新增：

```text
capital_range: under_5w | 5_20w | 20_50w | 50_100w | over_100w | undisclosed
```

`UserProfileManager._default_profile` 不写入 `capital_range`（缺省 = 未设置）。`update_profile` / `POST /profile`：

- 省略字段：不改
- 合法键：写入
- `null` 或 `""`：删除该字段（设置页「未设置」）
- 其他值：`ValueError`，返回 `{ success: false, error }`

`completeness()` 不变：仍检查 `experience_level`、`risk_tolerance`、`investment_horizon`、`favorite_sectors` 四项。

`get_profile_summary()` 增加一行中文金额档位；未设置写「未指定」，`undisclosed` 写「暂不透露」。系统提示词继续走现有画像摘要注入。

### 7.2 HTTP / IPC

扩展现有 `GET /profile` 与 `POST /profile`，以及 `getProfile` / `saveProfile` IPC，使 `capital_range` 可读写。不新增独立「onboarding 画像」接口。

Onboarding 状态用主进程 IPC（例如读取/写入 `onboarding.json` 的 skip/complete），不经过 Python。

Agent 工具 `update_user_profile` 同步允许 `capital_range`，便于设置页与对话改档位共用后端校验。

## 8. 设置页

`ProfileView` 增加「可投资金额」下拉：上述 6 档 + 一项「未设置」（对应不传/清除）。完整度文案与缺失项列表不因金额或回避变化。回避板块、投资风格保持现有表单，向导第 4 步填过的回避会显示在这里。

## 9. 错误处理

- 向导保存失败：留在向导，不写 `completed`
- 跳过时画像保存失败：已进聊天，设置页完整度提示后续补
- 升级迁移失败：进聊天
- 非法 `capital_range`：后端拒绝，前端提示

## 10. 验收（手动）

不写自动测试、不生成 Mock。

1. 空配置目录启动 → 向导；走完 5 步 → 聊天；设置页能看到选项与金额档位
2. 向导中途跳过 → 再启动不再出现向导；已选步骤仍在画像里
3. 已有 1.0 配置目录启动 → 无向导，`onboarding.json` 为 `migrated`
4. Python 未就绪时点「开始使用」→ 等待/重试；失败不标完成
5. 设置页可改金额；完整度百分比仍只随原来 4 项变化
6. 新开对话时，系统侧画像摘要含金额档位（或「未指定」/「暂不透露」）

## 11. 后续切片（不在本 spec）

v1.1 其余三块各自单独 spec，顺序：仪表盘 → 结构化报告 → Watchlist。本向导写入的 `experience_level` 与 `capital_range` 供后续切片读取，本切片不实现分层 UI（仪表盘快捷入口、简版/完整报告）。
