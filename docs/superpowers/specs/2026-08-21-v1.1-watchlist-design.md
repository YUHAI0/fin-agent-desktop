# v1.1 自选股 / 观察列表（Watchlist）

> 状态：已实现  
> 日期：2026-08-21  
> 范围：v1.1 四块中的第四块（Watchlist）。Onboarding、仪表盘、结构化报告、研报夹已另有 spec / 实现。  
> 相关：`PortfolioView.tsx`、`StockDetailView.tsx`、`scheduler.py`、`portfolio.py`、价格提醒 Toast

## 1. 目标

关注但未买入的股票与持仓分开存放、分开查看。固定两组（候选买入 / 长期跟踪）；加入时自动挂 ±5% 相对昨收的异动任务；超阈值时 Toast，同一自然日每只只推一次。

## 2. 非目标

- 用户自定义分组、改名、删组
- Agent 工具（对话里「把茅台加入观察」）
- 独立路由 `/watchlist`、顶栏新按钮
- 仪表盘单独做自选卡片（触发后走现有预警历史，待关注能看到）
- 已持仓股票加入自选
- 云同步、自动测试、Mock

## 3. 已确认决策

- 入口：组合页增加「持仓 / 自选」Tab，不新开顶栏
- 分组固定两个：`candidate`（候选买入）、`track`（长期跟踪）；添加时必选，之后可改组
- 加入时自动创建 `watchlist_move` 任务，默认阈值 5%；可改 1–20 的整数百分比
- 涨跌幅相对**昨收**；`|pct_chg| >= alert_pct` 触发
- 触发后任务保留，写入 `last_fired_date`（`YYYYMMDD`），同一自然日不再推；第二天可再推
- 与现有一次性 `price_alert` 分开；提醒弹窗不展示、不管理 `watchlist_move`
- 添加入口：自选 Tab 搜股 + 个股详情「加入观察」
- 任意组合已持仓 → 不能加入；后来加进持仓 → 自动移出自选并删任务

## 4. 界面

### 4.1 组合页

页头标题仍为「投资组合」。页头下方原组合切换条之上（或替换其上方）增加两个 Tab：

| Tab | 内容 |
|-----|------|
| 持仓 | 现有组合切换条 + 总览 + 持仓列表，行为不变 |
| 自选 | 不显示组合切换条与持仓表 |

自选 Tab：

- 右上「添加自选」打开现有 `StockSearchModal`（`onPick`，不跳个股页）
- 选中后弹出选组：候选买入 / 长期跟踪，确认后写入
- 页面分两节，顺序固定：候选买入、长期跟踪。空节仍显示标题 +「暂无」
- 每行：名称、代码、现价、今日涨跌幅（红涨绿跌，与持仓 `toneClass` 一致）、分组切换、阈值（`±N%`）、移除
- 点名称/代码区域 → `/stock/:tsCode`
- 改组：下拉或两个小按钮，立刻 `POST /watchlist/group`
- 改阈值：点击 `±N%` 用现有 `prompt` 输入 1–20 整数
- 移除：确认框「从自选移除「名称」？异动提醒会一并取消。」
- 空列表（两组都空）：「还没有自选股」+ 引导点「添加自选」
- 已持仓代码在搜股确认后报错：「已在持仓中，不能加入自选」
- 已在自选：报错「已在观察列表」

### 4.2 个股详情

页头「让 Agent 分析此股」左侧增加观察按钮，三态：

| 状态 | 按钮 |
|------|------|
| 未持仓且未观察 | 「加入观察」→ 选组后加入 |
| 已在自选 | 「移出自选」→ 确认后移除 |
| 已持仓 | 不提供加入；灰色文案「已在持仓」 |

选组用轻量菜单（两选项），不要新开整页。

## 5. 数据

文件：`Config.get_config_dir()/watchlist.json`

```json
{
  "items": [
    {
      "id": "hex",
      "ts_code": "600519.SH",
      "name": "贵州茅台",
      "group": "candidate",
      "alert_pct": 5,
      "alert_task_id": "watchlist_move_600519.SH_ab12cd34",
      "created_at": 1710000000
    }
  ]
}
```

- `group` 仅 `candidate` | `track`
- `alert_pct` 整数 1–20，默认 5
- 上限 100 条；超出拒绝新增
- `ts_code` 用 `to_ts_code` 规范化；同一代码全局唯一（不能同时在两组）
- `name` 加入时用搜索结果或行情名称；拿不到则用代码

持仓检测：扫描**所有**组合的 `positions` 键（规范化后比较）。

## 6. API

均不要加入 `_CSRF_PROTECTED_PREFIXES`。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/watchlist` | `{ ok, items }`，每条附 `price`、`pct_chg`（行情失败则字段为 null，列表仍返回） |
| GET | `/watchlist/status` | `?ts_code=` → `{ ok, held, item }`，供个股页三态按钮 |
| POST | `/watchlist/add` | body `{ ts_code, group, name? }` → `{ ok, item }` 或 `{ ok:false, error }` |
| POST | `/watchlist/group` | body `{ id, group }` |
| POST | `/watchlist/alert-pct` | body `{ id, pct }`，同步改任务的 `pct` |
| POST | `/watchlist/remove` | body `{ id }` |

错误文案（用户可见，简体中文）：

- 已持仓：`已在持仓中，不能加入自选`
- 已存在：`已在观察列表`
- 满员：`自选最多 100 只`
- 分组非法：`分组无效`
- 阈值非法：`阈值须为 1 到 20 的整数`
- 未找到：`未找到该自选`

`create_position` / `add_position` 成功写入持仓后，按 `ts_code` 调用 `WatchlistStore.remove_by_ts_code`（懒加载，避免循环 import）。

IPC：`listWatchlist`、`addWatchlist`、`setWatchlistGroup`、`setWatchlistAlertPct`、`removeWatchlist`。

## 7. 调度

`TaskScheduler` 增加类型 `watchlist_move`：

```json
{
  "id": "watchlist_move_600519.SH_ab12cd34",
  "type": "watchlist_move",
  "ts_code": "600519.SH",
  "pct": 5,
  "watchlist_item_id": "hex",
  "enabled": true,
  "created_at": 1710000000,
  "last_fired_date": null
}
```

轮询：`check_conditions` 在 `price_alert` 旁处理该类型。

触发条件：

1. `enabled` 为真
2. 能取到现价；`pre_close > 0`
3. `pct_chg` 优先用行情字段，否则 `(price - pre_close) / pre_close * 100`
4. `abs(pct_chg) >= pct`
5. `last_fired_date !=` 今天 `YYYYMMDD`

触发动作（对齐 `price_alert`，但**不删除任务**）：

- `AlertHistoryStore.append`，`message` 如：`贵州茅台(600519.SH) 今日上涨 6.2%，超过观察阈值 5%`
- `notification_sink`：`type: "watchlist_move"`，`title`/`body` 用同一套文案；点击主窗口跳 `/stock/:tsCode`（与价格提醒相同）
- 邮件：若已配置邮箱，主题 `[Fin-Agent] 自选异动 …`，正文用 `message`
- 写回 `last_fired_date`

`list_tasks` / 提醒弹窗：过滤掉 `type === 'watchlist_move'`，用户不能在弹窗里删掉导致自选孤儿任务。

加入自选时 `add_watchlist_move(...)`；移除或改 `ts_code`（本轮不改代码）时 `remove_task`；改阈值只更新 `pct`，不重置 `last_fired_date`。

Toast 标签：「自选异动」。高度/样式复用价格提醒变体。

## 8. 手工验收

1. 组合页出现持仓 / 自选 Tab；持仓行为与改前一致
2. 搜股加入候选买入，列表出现，个股页按钮变为「移出自选」
3. 改到长期跟踪，两条分组都对
4. 改阈值为 3，提醒弹窗里仍看不到这条任务
5. 对已持仓股票加入 → 中文错误；个股页显示「已在持仓」
6. 把自选里的股票加进持仓 → 自选消失
7. 移除自选 → 列表没了，对应 scheduler 任务没了
8. （交易时段）模拟或真实涨跌超阈值 → Toast「自选异动」，当天不再重复；仪表盘待关注能看到历史文案
