# v1.1 投资仪表盘（空会话首页）

> 状态：已实现  
> 日期：2026-08-21  
> 范围：v1.1 四块中的第二块（投资仪表盘）。结构化报告、Watchlist 不在本文。Onboarding 已另有 spec。  
> 相关：`ChatView.tsx` 空会话、`portfolio.py`、`alert_history.py`、资讯流、`POST /profile` 关注板块

## 1. 目标

把空会话欢迎区换成顾问仪表盘：当前组合总览、今日简报、待关注事项、三条场景入口。用户仍留在 `#/chat`；一开始对话，仪表盘让位给消息流。

## 2. 非目标

- 独立路由 `/dashboard`（本轮明确不采用）
- 按 `experience_level` 切换场景入口或卡片（留给结构化报告）
- 真实投资日历数据（v1.2）；本轮仅文案占位
- 点评按自然日自动缓存；本轮仅用户点击才生成
- 定时盘前/盘后简报（v1.2）
- Watchlist、结构化报告 UI、研报夹
- 云同步、自动测试、Mock

## 3. 已确认决策

- 仪表盘嵌在聊天空会话（`showWelcomeHero`），不新开页
- 四块全做：总览、简报（大盘 + 新闻 Top 3 + 一句话点评）、待关注（预警 + 日历占位）、场景入口
- 原欢迎标题、副标题、默认快捷语句去掉，由场景入口替代
- 点评用现有 LLM，且**仅**点击「生成点评」时请求
- 无持仓：总览引导去添加；简报仍放大盘；新闻按关注板块，否则全市场 Top 3
- 总览可切换组合，默认 `active_portfolio_id`；切换会持久化
- 「分析一只股票」打开现有搜索框，选中后在当前空会话发送分析，不跳个股页
- 「组合体检」复用 `buildPortfolioDiagnosePrefill`；无持仓先提示添加
- 「今日该关注什么」立刻发送带简报上下文的中文提示
- 大盘固定沪深300
- 不按新手/老手分层本切片

## 4. 出现时机

仅当当前会话没有用户/助手消息（现有 `showWelcomeHero === true`，含草稿空会话与清空后的空会话）。

发出任意一条消息后仪表盘卸载；切回该空会话或新建空会话再显示。侧栏、顶栏、输入框布局不变。输入框在仪表盘展示期间始终可用。

向导结束、升级用户启动仍进 `#/chat`（空会话即仪表盘）。不改 `onboarding.json` 分流目标。

## 5. 界面

主栏可滚动区域从上到下：

### 5.1 组合总览

- 标题：当前组合名；右侧下拉为 `portfolios` 列表
- 有持仓：三列「总市值」「今日盈亏」「累计盈亏」；涨跌色与组合页 `toneClass` 一致（红涨绿跌）
- 无持仓：不展示 0；文案「还没有持仓」+ 按钮「去添加」→ `/portfolio`
- 点数字区域（有持仓时）→ `/portfolio`

切换组合：先 `POST /portfolio/active`，成功后再 `GET /dashboard/summary`。

### 5.2 今日简报

- 一行沪深300：名称、现价、涨跌幅；指数为 `null` 时写「大盘暂不可用」
- 最多 3 条新闻：标题、来源；有 `url` 则外部浏览器打开。若条目带本地资讯 `id`，同时标已读；无本地 id（全市场临时拉取）只打开链接、不写已读库
- 「生成点评」默认不请求。点击后按钮 disabled，成功渲染一句中文；失败「点评暂不可用」，可再点。点评**不**写入 session / UI 消息列表

### 5.3 待关注

- 最多 5 条最近价格预警，文案用历史记录里的 `message`（已有语义化文案）
- 点击一条打开现有 `ReminderTasksModal`（与顶栏铃铛同一弹窗）
- 无预警：「暂无预警」
- 固定一行不可点灰色文案：「投资日历即将推出」

### 5.4 场景入口

三条，所有用户相同：

| 入口 | 行为 |
|------|------|
| 分析一只股票 | 打开 `StockSearchModal`；选中后关闭弹窗，在**当前空会话** `requestPrefill(buildAnalyzeStockPrefill(tsCode, name))`。不 `navigate` 到 `/stock/:tsCode`（与顶栏搜索进个股页区分：仪表盘路径需要 `onPick` 回调） |
| 组合体检 | 无持仓：对话框「请先添加持仓」。有持仓：`requestPrefill(buildPortfolioDiagnosePrefill(id, name))` |
| 今日该关注什么 | 立刻 `requestPrefill` 一段中文，包含当前组合名、沪深300涨跌（若有）、三条新闻标题（若有） |

`requestPrefill` 在空会话上会发出消息，仪表盘随 `showWelcomeHero` 变为 false。

## 6. 数据与 API

### 6.1 `GET /dashboard/summary`

Query：`portfolio_id` 可选；缺省为 `active_portfolio_id`。

若传入的 id 无效，回退当前组合，不 500。

响应：

```json
{
  "ok": true,
  "portfolios": [{ "id": "default", "name": "默认组合" }],
  "active_portfolio_id": "default",
  "snapshot": {
    "portfolio_id": "default",
    "portfolio_name": "默认组合",
    "has_positions": true,
    "total_market_value": 123456.78,
    "today_pnl": 120.5,
    "today_pnl_pct": 0.12,
    "total_pnl": 800.0,
    "total_pnl_pct": 0.65
  },
  "index": {
    "ts_code": "000300.SH",
    "name": "沪深300",
    "price": 3800.12,
    "change_pct": -0.85
  },
  "news_source": "holding",
  "news": [
    {
      "id": "...",
      "title": "...",
      "source": "...",
      "url": "...",
      "match": "holding"
    }
  ],
  "alerts": [
    {
      "id": "...",
      "message": "...",
      "triggered_at": 0
    }
  ]
}
```

约定：

- `has_positions === false` 时 `total_market_value` / `today_pnl` / `total_pnl` 及对应 pct 均为 `null`
- `index` 拉取失败为 `null`，`ok` 仍为 true
- `news` 不足 3 条就有多少返回多少；`news_source` 为实际采用的档：`holding` | `sector` | `market`
- 新闻筛选：先持仓代码匹配本地资讯（复用现有持仓匹配逻辑）；若 0 条且画像有 `favorite_sectors`，按板块关键词筛；仍 0 则全市场最新
- `alerts` 取 `AlertHistoryStore.list_items` 最近 5 条，不按组合过滤（预警是全局任务）
- `today_pnl`：各持仓 `(现价 - 昨收) * 数量` 求和；无昨收的标的不计入今日盈亏分子，也不把该持仓现价当昨收（避免把累计盈亏算进今日）
- 累计盈亏沿用 `get_portfolio_status` 的 `total_pnl`

整体不可用（Python 未起等）时 IPC/HTTP 失败，前端不展示假数字。

### 6.2 `POST /portfolio/active`

```json
{ "id": "default" }
```

调用已有 `PortfolioManager.set_active_portfolio`。成功 `{ "ok": true, "active_portfolio_id": "..." }`；未知 id `{ "ok": false, "error": "组合不存在" }`。

### 6.3 `POST /dashboard/comment`

```json
{
  "portfolio_id": "default",
  "index": { "name": "沪深300", "change_pct": -0.85 },
  "news_titles": ["...", "..."]
}
```

用当前已配置 LLM 生成**一句**简体中文市场点评，不超过 80 个汉字，不要列表、不要 Markdown。系统提示要求结合指数涨跌与新闻标题，不荐股、不编造未提供的数据。

成功 `{ "ok": true, "comment": "..." }`。未配置模型 / 调用失败 `{ "ok": false, "error": "中文原因" }`。

不写入 sessions、不调用 `query_news` 工具循环。

## 8. 错误处理

- summary 请求失败：仪表盘区域单行「仪表盘加载失败，可直接在下方提问」+「重试」；输入框可用
- 指数 / 新闻 / 预警某一支在后端已降级为 null/[]：前端用对应空文案，不视为整页失败
- 点评失败：不关闭简报其他内容
- 切换组合失败：保持原组合，中文提示
- 不使用 Mock 数据占位

## 9. 验收（手动）

不写自动测试、不生成 Mock。

1. 空会话出现四块；原「今天想分析什么？」和欢迎快捷语句不再出现；发送一条消息后仪表盘消失
2. 无持仓：总览引导添加；简报仍尝试大盘；新闻为板块或全市场
3. 有持仓：累计盈亏与组合页一致；今日盈亏为昨收估算
4. 下拉切换组合会写入 `active_portfolio_id`；再开空会话仍为该组合
5. 未点「生成点评」时网络侧不应出现 `/dashboard/comment`；点了失败可重试；聊天记录无点评气泡
6. 分析一只股票：搜索选中后当前会话发出分析，地址栏仍为 `#/chat`
7. 组合体检：无持仓提示；有持仓发出与组合页相同的诊断预填
8. Python 未就绪：仪表盘失败提示，输入框仍可输入（发送仍会等后端，行为与现网一致）
