# v1.1 Watchlist Implementation Plan

> **For agentic workers:** 本会话直接实现。步骤用 checkbox 跟踪。

**Goal:** 组合页「自选」Tab 管理未持仓股票（候选买入 / 长期跟踪），加入时自动挂相对昨收 ±N% 的 `watchlist_move` 任务，超阈值 Toast 且同日不重复。

**Architecture:** 独立 `watchlist.json` + `WatchlistStore`。加入/移除同步 `TaskScheduler` 的 `watchlist_move`。持仓写入时按代码驱逐自选。UI 只改 `PortfolioView` 与 `StockDetailView`。

**Tech Stack:** Electron IPC、React + TypeScript、`python/api.py`、`scheduler.py`、现有搜股框 / Toast。

**Spec:** `docs/superpowers/specs/2026-08-21-v1.1-watchlist-design.md`

## Global Constraints

- 固定两组：`candidate` / `track`；默认阈值 5，可改 1–20 整数。
- 相对昨收；`|pct_chg| >= pct`；`last_fired_date` 同日去重；触发后不删任务。
- 已持仓不能加入；加持仓则驱逐自选。
- 提醒弹窗过滤 `watchlist_move`。
- `POST /watchlist/*` **不要**放进 CSRF 前缀。
- 不生成 Mock；不编译；不写自动化测试；不 git commit。
- 面向用户文案简体中文。
