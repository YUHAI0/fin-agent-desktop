# Fin-Agent Desktop v1.0.1 Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 发布 1.0.1：打磨现有对话 / 画像 / 个股 / 提醒 / 组合 / 新闻 / 数据源体验，打通「数据 → 结论 → 行动」闭环，不引入仪表盘 / Watchlist / 研报夹等大模块。

**Architecture:** 保持 Renderer → Electron IPC → `python/api.py` → `fin_agent` 三层。新增 `/profile` HTTP、调度器百分比换算与触发历史、组合行业聚合；前端用统一 `prefill` 跳转聊天；Agent 靠 system prompt 做报告结构与新手/老手分层。

**Tech Stack:** Electron + React + TypeScript（renderer）、Python `api.py` 自建路由、`fin_agent.user_profile` / `scheduler` / `portfolio` / `agent.core`、akshare/tushare provider。

**Spec:** `docs/superpowers/specs/2026-08-13-v1.0.1-polish-design.md`  
**Roadmap:** `ROADMAP.md` § v1.0.1

## Global Constraints

- 版本号最终为 `1.0.1`（本计划最后一任务再改 `VERSION` / package）。
- 不新增独立服务进程；不实现仪表盘、Onboarding、Watchlist、研报夹。
- 不生成 Mock 代码；不做项目编译；实现后由用户手动验收（任务内「Verify」为手动检查清单，勿跑全量 build）。
- 所有面向用户文案使用简体中文。
- 分析类长回复须含「非投资建议」类免责；简单确认可省略。
- `experience_level` 取值仅允许：`beginner` | `experienced`（UI：新手 / 老手）。

```typescript
export function buildAnalyzeStockPrefill(tsCode: string, name?: string): string {
  const label = name ? `${name}（${tsCode}）` : tsCode
  return `请按「结论 → 依据 → 风险 → 下一步」结构，对 ${label} 做个股体检分析。`
}

export function buildPortfolioDiagnosePrefill(portfolioId: string, portfolioName?: string): string {
  const label = portfolioName ? `「${portfolioName}」` : ''
  return `请诊断当前组合${label}（id=${portfolioId}）：按结论→依据→风险→下一步给出健康度与调仓建议；先调用持仓工具获取真实数据。`
}

export function buildNewsImpactPrefill(title: string, body: string, relatedCodes: string[] = []): string {
  const codes = relatedCodes.length ? `相关标的：${relatedCodes.join('、')}。` : ''
  return `请分析以下新闻对我当前持仓的影响（结论→依据→风险→下一步）。${codes}\n标题：${title}\n内容：${body.slice(0, 800)}`
}

export function encodePrefillQuery(text: string): string {
  return encodeURIComponent(text)
}
```

- [ ] **Step 2: 扩展 ChatContext**

在 `ChatContextType` 增加：

```typescript
requestPrefill: (text: string) => Promise<void>
setSessionStreaming: (sessionId: string, streaming: boolean) => void
isActiveSessionStreaming: () => boolean
```

实现要点：
- 用 `useRef<Record<string, boolean>>` 记录各会话流式状态。
- `requestPrefill`：若 `isActiveSessionStreaming()` 为 true，先 `await newSession()`；再 `navigate` 或通过自定义事件把文本交给 ChatView（推荐：`sessionStorage.setItem('fa-prefill', text)` + `navigate('/chat')`，ChatView `useEffect` 读取并清空）。
- 勿自动发送；将文本填入输入框并 focus，由用户确认发送（更安全）。若产品已有一键发送惯例，可改为自动 `send`——**本计划采用：填入输入框并自动发送**（顾问场景更顺畅）。实现时调用 ChatView 暴露的发送逻辑：用 `window` 自定义事件 `fa-prefill-send`，detail 为 `{ text }`。

- [ ] **Step 3: ChatView 接入**

- `useEffect` 监听 `fa-prefill-send` 与 `searchParams.get('prefill')`：解码后写入输入框并触发与点击发送相同的 handler，然后 `navigate('/chat', { replace: true })` 清掉 query。

def handle_profile_get(req):
    from fin_agent.tools.profile_tools import get_profile_manager
    pm = get_profile_manager()

@route("POST", "/profile")
def handle_profile_save(req):
    from fin_agent.tools.profile_tools import get_profile_manager
    pm = get_profile_manager()
    body = req.body or {}
    try:
        pm.update_profile(
            risk_tolerance=body.get("risk_tolerance"),
            investment_horizon=body.get("investment_horizon"),
            favorite_sectors=body.get("favorite_sectors"),
            avoid_sectors=body.get("avoid_sectors"),
            investment_style=body.get("investment_style"),
            experience_level=body.get("experience_level"),
        )
    except ValueError as e:
        return {"success": False, "error": str(e)}
    return {"success": True, "profile": pm.get_profile(), "completeness": pm.completeness()}
