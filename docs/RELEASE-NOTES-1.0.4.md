# Fin-Agent Desktop 1.0.4 更新说明

**版本号：** 1.0.4  
**发布日期：** 2026-08-19  
**定位：** 1.0.3 之后的使用路径修补 — 资讯流右键进对话、长对话超限、已删持仓仍推新闻。

---

## 本版本亮点

- 资讯流右键把新闻以**卡片**发进**新对话**分析，不再把整段正文粘进输入框
- 超长工具结果与会话历史会自动压缩，减少模型上下文超限
- 删除持仓后，待推送的「持仓新闻」不再弹出

---

## 详细更新

### 资讯流右键分析

- 单条新闻支持右键（以及菜单键）：**解读这条新闻**、**对我持仓的影响**、**接下来可以做什么**
- 新闻带相关代码、或标题/摘要能对上当前持仓时，额外出现 **分析相关个股**
- 点菜单项后始终新建对话并立刻发送；正在回复的旧会话不会被打断
- 对话里用户消息是新闻卡片（标题、来源、时间、利好/利空、原文/仅摘要、相关代码），摘要最多两行
- 有原文链接时可点标题用系统浏览器打开；仅摘要则不跳外链
- 发给模型的是一句短意图 + 结构化附件，不是用户手打的长文
- 左键行为不变：有链接打开原文并标已读，没有链接只标已读
- Toast「分析这条新闻对我持仓的影响」、个股体检、组合诊断仍走原来的纯文本预填

### 对话上下文超限

- 工具返回写入模型历史时截断超长 JSON（界面当轮仍可展示完整结果）
- 调用模型前只保留 system 与最近若干完整轮次，旧工具结果再压缩
- 仍超出窗口时自动再压一轮后重试；仍失败则提示开新对话，不再甩英文 400

### 持仓新闻推送

- 桌面通知真正发出前，再按当前订阅与持仓过滤
- 已从组合删除的标的，积压的「持仓新闻」会标为已处理，不再弹出

---

## 升级说明

1. 安装包版本号为 **1.0.4**（如 `Fin-Agent-1.0.4-x64.exe`）
2. 建议**完全退出再打开**（托盘也要退出），以便主进程与 Python sidecar 加载本版本
3. 既有配置、组合、提醒任务、新闻订阅与 1.0.3 数据均会保留
4. 已经很长的旧对话，再发一条时会自动压缩历史；若仍提示过长，请新开对话
