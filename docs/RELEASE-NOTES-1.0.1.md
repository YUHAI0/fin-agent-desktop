# Fin-Agent Desktop 1.0.1 发布说明

**发布日期：** 2026-08-13  
**定位：** 现有能力打磨 — 打通「数据 → 结论 → 行动」顾问闭环，不引入大型新模块。

---

## 对话与 Agent

- 分析类回复统一为 **结论 → 依据 → 风险 → 下一步行动** 四段结构，末尾附简短免责声明。
- 快捷回复改为行动导向（设提醒、组合诊断、深入指标等），减少「再查一次现价」类选项。
- 根据用户画像 `experience_level`（新手 / 老手）调整术语深度与回复密度；画像变更后每轮对话热更新 system prompt。
- 工具失败时输出友好中文说明与替代方案；无 Tushare Token 时禁止循环调用需 Token 的工具。

## 聊天预填基础设施

- 新增 `requestPrefill` 与 `chatPrefill` 工具函数，支持从个股页、组合页、新闻 Toast 跳转聊天并自动发送预填文案。
- 流式输出进行中触发预填时先新开会话，不打断当前回复。

## 个股详情页

- 新增「**让 Agent 分析此股**」按钮，预填个股体检分析意图并跳转聊天。
- K 线周期扩展至 **3Y / 5Y**（后端 lookback 2000 天）。

## 用户画像

- 设置页新增**投资画像**表单：经验等级、风险偏好、投资周期、关注/回避板块、投资风格。
- 新增 `experience_level` 字段（新手 / 老手 / 未知）及完整度评分与缺失项提示。
- 提供 `GET/POST /profile` API 与 Electron IPC。

## 提醒系统

- 提醒弹窗增加「当前提醒 / 触发历史」页签。
- 支持按**百分比涨跌幅**创建提醒（自动换算绝对阈值）；无法获取现价时友好拒绝创建。
- 提醒触发后写入 `alert_history.json`，可在历史中查看。

## 投资组合

- 组合详情展示**行业分布简表**与**持仓集中度**（前一 / 前三 / HHI）。
- 新增「**组合诊断**」按钮，预填诊断意图并跳转聊天；无持仓时提示先添加持仓。

## 新闻

- 资讯流标注与当前持仓相关的新闻（「持仓相关」标签）。
- 新闻 Toast 增加「**分析对持仓影响**」快捷动作，聚焦主窗口并预填分析文案。

## 数据源体验

- 设置页在未填 Tushare Token 时列出需 Token 的高级能力清单。
- akshare 日线与实时行情关键路径增加自动重试（失败间隔 0.4s，最多额外 2 次）。

---

## 升级说明

- 安装包版本号同步为 **1.0.1**（`Fin-Agent-1.0.1-x64.exe` 等）。
- 建议重启应用以使 Python sidecar 加载新 API 与 prompt 规则。
