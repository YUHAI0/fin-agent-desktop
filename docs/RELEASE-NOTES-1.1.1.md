# Fin-Agent Desktop 1.1.1 更新说明

**版本号：** 1.1.1  
**发布日期：** 2026-09-07  
**定位：** 1.1.0 结构化报告路径修补 — 回复半句中断、生成报告时卡住、空卡片、表格变成竖线原文。

---

## 本版本亮点

- 个股体检等分析回复不再停在「需带 / 提供 / output needs the」半句上无声结束
- 生成结构化报告时先出现「正在生成报告…」，不再干等很久再突然弹出一大片
- 报告卡展示结论 / 依据 / 风险 / 下一步，并与分析正文同时保留
- Markdown 表格不再被收成竖线原文

---

## 详细更新

### 回复被截断

- 报告 JSON 未写完时不再从界面静默丢掉，并提示可发送「继续」
- 默认输出上限提到 8192 token，降低思考 + 长报告顶满默认 4096 后停在半句的情况
- 识别 DeepSeek / Qwen / GLM 的思考字段；模型未返回完整对象时给出明确错误，而不再空结束

### 报告生成过程

- 一碰到报告标记就显示「正在生成报告…」卡片和动画
- JSON 校验通过后立刻换成真正的个股体检 / 组合诊断 / 买卖备忘录卡
- 清掉「需带 FIN_AGENT_REPORT_JSON」「depth 按画像」这类规划句和「提供」半截尾巴，不误删分析正文

### 报告卡与分析正文

- 卡片渲染结论、依据、风险、下一步（支持 Markdown）及免责声明
- 分析 Markdown 正文保留在卡片上方，两者同时存在
- 清理规划句时不再把表格行拆成空行分隔，GFM 表格可正常显示

---

## 升级说明

1. 安装包版本号为 **1.1.1**（如 `Fin-Agent-1.1.1-x64.exe`）
2. 建议**完全退出再打开**（托盘也要退出），以便主进程与 Python sidecar 加载本版本
3. 既有配置、组合、提醒、新闻订阅、自选与研报夹均会保留
4. 已经生成过的旧回复不会自动重绘表格或补上卡片章节，需重新提问一次
