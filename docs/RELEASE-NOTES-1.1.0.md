# Fin-Agent Desktop 1.1.0 更新说明

**版本号：** 1.1.0  
**发布日期：** 2026-09-02  
**定位：** 从「金融数据对话助手」升级为「个人智能投资顾问」— 仪表盘首页、Onboarding、结构化报告、自选股与自选新闻订阅。

---

## 本版本亮点

- 新安装走 5 步投资画像向导；空对话首页变成组合总览、简报、待关注与场景入口
- 个股体检 / 组合诊断 / 买卖备忘录以报告卡呈现，可收藏到研报夹查看
- 组合页增加自选 Tab：候选买入 / 长期跟踪，相对昨收异动 Toast；对话可加入/查看/移出自选
- 新闻订阅新增「自选」类型，自动跟随所选分组；组合/自选订阅名称固定为「持仓新闻」「自选新闻」
- 搜股票改走腾讯联想，按名称搜「茅台」可即时出结果
- Windows 11 / macOS 窗口改用系统 Mica / Vibrancy，不再用假玻璃遮罩

---

## 详细更新

### Onboarding 与投资画像

- 首次启动 5 步问卷：经验、风险、周期、关注板块、可投资金额
- 写入现有 `user_profile.json`；设置页仍可改画像
- 已有用户不会被强制再走向导
- 投资画像页顶栏与新闻/组合等页对齐

### 投资仪表盘（空会话首页）

- 空对话不再显示欢迎 Hero，改为当前组合总览（可切换组合）
- 今日简报：沪深 300、持仓/关注相关新闻 Top 3、可点「生成点评」
- 待关注：已触发的价格预警；投资日历仍为占位
- 场景入口：「分析一只股票」「组合体检」「今日该关注什么」
- 发出任意消息后仪表盘让位给对话；新空会话再显示

### 结构化报告与研报夹

- 分析类回复抽出 `FIN_AGENT_REPORT_JSON` 后渲染报告卡（结论 / 依据 / 风险 / 下一步）
- 深度跟随画像：新手简版、老手完整、未填适中
- 卡片可收藏完整副本；顶栏书签进入 `#/reports` 研报夹，左列表右详情，可取消收藏
- 删会话后收藏仍保留

### 自选股 / 观察列表

- 组合页「持仓 / 自选」Tab；固定两组：候选买入、长期跟踪
- 加入时自动挂 ±5% 相对昨收异动任务（可改 1–20）；同一自然日每只只推一次
- 已持仓不能加入；后来加进持仓则自动驱逐自选
- 个股详情「加入观察 / 移出自选」
- Agent 工具：`add_watchlist` / `list_watchlist` / `remove_watchlist`

### 新闻订阅

- 新增类型 `watchlist`：一条订阅可勾选一组或两组自选，动态跟随，不必手填代码
- 组合、自选订阅不再让用户填名称，分别固定为「持仓新闻」「自选新闻」
- 自选增删或改分组后，下一轮轮询生效

### 搜股票与窗口材质

- 名称搜索不再每次拉全市场代码表；改用腾讯联想接口（东财联想已改版，无法用于搜股）
- 代码搜索失败时仍回退按代码查单只
- Windows 11 使用系统 Mica，macOS 使用窗口 Vibrancy

## 升级说明

1. 安装包版本号为 **1.1.0**（如 `Fin-Agent-1.1.0-x64.exe`）
2. 建议**完全退出再打开**（托盘也要退出），以便主进程与 Python sidecar 加载本版本
3. 既有配置、组合、提醒、新闻订阅与 1.0.4 数据均会保留
4. 自选、研报夹为新的本地文件（`watchlist.json`、研报收藏），不影响旧持仓
5. 已有用户不会自动弹出 Onboarding；新安装会走向导
