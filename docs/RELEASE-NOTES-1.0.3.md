# Fin-Agent Desktop 1.0.3 更新说明

**版本号：** 1.0.3  
**发布日期：** 2026-08-17  
**定位：** 1.0.2 之后的体验修补 — 提醒弹窗、本地模型、多会话、应用内更新，以及新股行情工具。

---

## 本版本亮点

- 股价提醒 Toast 按文案自适应高度，长语义不再被截成「当前 …」
- 多标签会话：等待三点只出现在正在回复的对话；侧栏标签右侧显示旋转状态
- 「立即安装」能真正拉起安装程序，失败时在更新浮窗给出原因
- 对话与更新说明中的 http(s) 链接改为系统浏览器打开，不再把应用窗口跳走
- 新增 Agent 工具「查询新股行情」，东财直连失败会自动换镜像并回退新浪次新股

---

## 详细更新

### 股价提醒弹窗

- 股价提醒正文改为自动换行，窗口高度随内容升高（上限 220px）
- Toast / 邮件 / 历史仍使用 1.0.2 的语义化文案；本版本补齐展示层裁切问题

### 本地模型

- 设置页下拉**仅列出本机已安装模型**，不再把 `.env` 里未安装的模型（如 `qwen2.5:7b`）当可选项
- 刷新列表后若当前模型不在已安装列表，自动改选第一个可用模型，并提示需「保存配置」后才对对话生效
- Ollama 返回 404 model not found 时，Agent 给出中文指引（刷新列表 / `ollama pull`）

### 多会话

- 等待三点（输入区上方跳动圆点）按**当前标签**推导，不再把 A 会话的等待态带到 B
- 正在流式回复的侧栏标签右侧显示旋转图标，切走后该标签仍会转，回复结束自动消失

### 应用内更新

- 下载完成后点「立即安装」：Windows 用系统打开安装包；安装过程跳过「正在生成」退出确认
- 安装包文件失效或启动失败时，浮窗显示错误，可重新下载
- 仅在下载进行中取消时才删除临时安装包，避免关浮窗后「立即安装」无文件可开

### 外链

- 聊天 Markdown、更新说明、以及应用内任意 `http/https` 锚点，一律用系统默认浏览器打开
- 主进程拦截页内跳转与新窗口，避免点链接后应用变成网页且无法返回

### Agent 工具

- 新增 **`get_new_share_quotes`（查询新股行情）**：东方财富新股板块实时行情（涨跌幅、成交额、上市日期等）
- 支持 `keyword` / `ts_code` 筛选与 `limit`（默认 20，最多 50），默认按涨跌幅降序
- 优先直连东财 `push2` 单页拉取并多镜像重试；失败再试 AkShare，最后回退新浪次新股
- 全部源失败时返回中文「行情源暂时连不上」，不再把 `RemoteDisconnected` 原文甩给对话

---

## 升级说明

1. 安装包版本号为 **1.0.3**（如 `Fin-Agent-1.0.3-x64.exe`）
2. 建议**完全退出再打开**（托盘也要退出），以便主进程与 Python sidecar 加载本版本修复
3. 既有配置、组合、提醒任务与 1.0.2 数据均会保留
4. 本地模型若在设置页被自动改选，需点一次「保存配置」后对话才会用新模型

## 本版本明确不做

以下能力仍不在 1.0.3 范围：

| 能力 | 计划版本 |
|------|----------|
| 投资仪表盘、Watchlist、定时简报 | v1.1 / v1.2 |
| 新闻结果写入本地库 / 资讯流新能力 | 后续版本 |
| 本地模型能力自动探测 / 标注 | 后续版本 |
| 打新申购、中签率日历（本版本只有新股实时行情列表） | 后续版本 |

完整路线图见项目根目录 `ROADMAP.md`。
